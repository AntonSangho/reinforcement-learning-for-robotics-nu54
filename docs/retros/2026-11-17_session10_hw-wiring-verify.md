## 2. 잘된 점

- **같은 시험을 고정했다.** A ±30 % → B ±30 % → 동시 50 %를 매번 똑같이 돌려서, 배선을 바꿀 때마다 숫자를 바로 비교할 수 있었다 (옮기기 전 ±2610 기준).
- **켜 둔 채 전압을 쟀다.** 선을 계속 다시 꽂는 대신 `motor a 50`을 켜 두고 PWMA·AIN1·AIN2를 재서, "AIN1·AIN2가 둘 다 1.6 V"라는 단서로 단락을 찾았다.
- **바퀴 방향으로 범위를 좁혔다.** 부호가 반대일 때 두 바퀴가 반대로 돈다는 관찰 하나로 엔코더가 아니라 구동 선(AIN)임을 가렸다.
- 이상한 측정값이 나오자 먼저 모터를 껐다 (출력 핀끼리 서로 당기는 상태).

## 3. 시간이 걸린 점과 원인

| 문제 | 원인 | 다음에는 |
|---|---|---|
| 안 돎 ×3 | DC-DC 스위치 J2 OFF | 시험 전 확인 목록 첫 줄에 J2 ON. 두 모터 모두 ±10틱 이하면 J2부터 |
| 측정값 없이 "다시 해 주세요" 반복 | 원인을 모른 채 재시험 | 같은 결과가 두 번 나오면 측정(VM, 핀 전압)으로 넘어간다고 미리 말한다 |
| AIN1·AIN2·PWMA가 모두 1.6 V로 보여 셋 다 단락으로 오해할 뻔함 | PWMA 50 %의 평균이 우연히 1.6 V | 기대값이 같은 핀끼리는 도통 시험으로 가린다 |
| 단락을 고치면서 AIN 순서가 바뀜 | 선을 옮기면서 번호 확인 안 함 | 고친 뒤 바로 정·역 시험으로 확인 (이번에 그렇게 해서 찾음) |
