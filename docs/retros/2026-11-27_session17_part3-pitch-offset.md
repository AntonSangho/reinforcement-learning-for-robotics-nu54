## 2. 잘된 점

- **측정을 조건별로 버렸다.** 균형점 6회 중 손가락에 받친 3회와 케이블이 당긴 1회를 사용자 설명을 듣고 뺐다. 특히 4회차는 "10번 모두 같은 값"이라는 숫자의 모양에서 이상을 먼저 짚었다.
- **엔코더 문제를 핀 레벨로 좁혔다.** 2초 구동 후 틱만 보던 것을 모터를 켜 둔 채 `enc info`의 A·B 레벨을 반복해서 읽는 방식으로 바꾸자 "두 모터 모두 B상만 1 고정"이 바로 보였다. 3.3 V 문제 → 초록 선 문제로 두 단계를 나눠 찾음.
- **새 기능이 만든 부작용을 바로 설명했다.** O2에서 "버튼으로 시작이 안 된다" → offset이 시작 각도 범위도 옮긴다는 것을 표로 보여 주고, 사용자의 시작 습관(−4\~−8°)이 균형점보다 약 15° 뒤라는 것까지 연결했다.
- **관찰을 먼저 받았다.** O1·O3는 숫자 전에 "어땠나요"를 물었고, O3의 "O2보다 빨리"가 2초 시점 바퀴 속도(5.8 → 8.4 rad/s)와 맞았다.

## 3. 시간이 걸린 점과 원인

| 문제 | 원인 | 다음에는 |
|---|---|---|
| 균형점 1·2회차가 무효 | "손끝에 힘이 안 느껴지는 자세"가 무슨 뜻인지 전달이 안 됨. 사용자는 젖혀서 받침 | 처음부터 "두 손가락 사이, 어디에도 닿지 않고 1초 버티는 자세"로 안내 |
| 4회차 무효 | USB 케이블이 당김. "다시 재 주세요"를 받자마자 잼 | 측정은 항상 "준비됨" 뒤에. 케이블을 느슨하게 두라고 먼저 말한다 |
| RUN 전 점검에서 "바퀴가 돌았나" 질문을 여러 번 반복 | 틱 0만 보고 전원·엔코더를 가르려 함 | 틱이 0이면 바로 `motor x 30`을 켜 둔 채 레벨 반복 읽기 + 바퀴 움직임을 함께 묻는다 |
| safety tip 잠금 | 바퀴를 들면서 46°까지 기울어짐 | 모터 명령 전에 `safety info`로 pitch와 lock을 같이 본다 (이번엔 응답의 `locked`로 앎) |
| O2 첫 기록이 사라짐 | `policy dump`는 마지막 RUN만. 정지 뒤 버튼을 한 번 더 눌러 1.2초 RUN이 덮어씀 | 안내에 "정지는 한 번, 그 뒤 버튼 누르지 않기"를 처음부터 넣는다 |
| USB가 빠진 채 명령 | 사용자가 꽂기 전에 "확인해 주세요" | `baram-ctl status`의 `connected`를 먼저 본다 (이번에도 그렇게 해서 빈 파일을 지움) |
| `log boot`의 Boot count가 가끔 안 나옴 | 링 버퍼 출력이 잘리는 것으로 보임 (원인 확인 안 함) | offset 값이 유지됐는지(재부팅 시 0)를 대신 증거로 씀 |

## 4. 알게 된 것 (해석은 사용자 몫, 질문으로 남김)

- 균형점에서 IMU는 0°가 아니라 약 +9.5°를 읽는다. 세션 10의 "직립 −2.7°"는 균형점이 아니라 손으로 잡은 자세였다
- 그런데 offset을 균형점 쪽으로 키울수록(0 → 6 → 9.5) **앞으로** 더 빨리 달려 나갔다. 세션 16(offset 0)은 **뒤로** 가속하다 넘어졌다 → `rl-notes` Q7
- O2·O3에서 정책이 본 pitch는 ±0.05 rad 안이었는데 바퀴 속도는 9 rad/s까지 올랐다
- 무게중심은 높이(30 mm)만 쟀고 앞뒤는 "가운데로 가정"이다. 무게중심이 낮으면 앞뒤 몇 mm 차이도 균형 각도를 크게 바꾼다. IMU 장착 기울기와 구분할 방법은 아직 없다
- 질량은 모델보다 +8.8 %, 배터리 외 부품이 +104 g. 어느 높이에 있는지는 모른다
